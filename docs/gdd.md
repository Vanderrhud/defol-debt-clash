# 📜 Game Design Document (GDD): DEFOL: Debt Clash

## 1. Visi Game
Game fighting 2D mobile bertempo arcade yang menggabungkan keseriusan estetika cyberpunk dengan kekonyolan jurus *over-the-top* (OTT). Pertarungan fokus pada positioning, timing combo sederhana, dan eksploitasi bar *Bunga Meter*.

## 2. Target Pemain & Platform
* **Platform:** Mobile (Android & iOS) dan Tablet.
* **Orientasi:** Landscape.
* **Target Audience:** Penggemar game fighting kasual hingga mid-core, pecinta humor slapstick/anime absurd.

## 3. Game Loop
1. **Pilih Karakter & Arena** (misal: Atap Gedung Bank Turki, Pasar Kebab Gelap).
2. **Match 1v1 (Best of 3 Rounds, 60s/round)**:
   - Saling serang dengan Light & Heavy attack untuk mencicil HP dan mengisi *Bunga Meter*.
   - Gunakan *Special Skill* untuk kontrol jarak / disrupt timing lawan.
   - Eksekusi *Absurd Ultimate* saat Bunga Meter penuh untuk membalikkan keadaan.
3. **End Round / Match:**
   - Animasi K.O. konyol sesuai jurus terakhir.
   - Layar hasil: Jumlah bunga/denda hutang yang berhasil dipotong.

## 4. Estetika & Art Style
* **Visual:** 2D Cel-shaded / Comic-Cyberpunk (garis tegas, palet neon kontras dengan sentuhan elemen Timur Tengah masa depan).
* **Audio:** Perpaduan musik Cyber-Synthwave dengan instrumen tradisional Turki (Saz / Oud elektrik) ber-beat cepat.
